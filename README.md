# Ass_1-Textbook_Gallery
Intro to Web Dev I Assignment 1: HTML &amp; CSS Only Website w/ Bootstrap for responsive grid layout

## Overview
In addition to replicating the demo video, I also added additional hover animations for a blue shadow when hovering over the book cards on the gallery page. AI was used in generating textbook overview descriptions and helping explain and debug hover states for CSS animations/transitions.
