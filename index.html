About This Site

This CMPT 272 Assignment 1 demo shows a CSS-only overlay button (hover + keyboard focus), plus reduced-motion and dark-mode support. Bootstrap is only used for the grid layout.

  • No JavaScript is used anywhere.
  • All interactivity is done with HTML and CSS only.
  • Images are optimized for web delivery.
  • Semantic HTML5 elements were used throughout.
  • Accessible roles are included.

Note: This is a fictional textbook gallery created for educational purposes only. The textbooks and authors mentioned are real, but their inclusion here does not imply endorsement or affiliation. I affirm that I have read and understood the SFU Academic Integrity Policy and that this assignment is my own work. AI was used in generating textbook overview descriptions and helping explain and debug hover states for CSS animations/transitions.
