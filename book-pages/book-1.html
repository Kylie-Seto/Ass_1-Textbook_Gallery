Basics of Web Design

HTML5 & CSS3 Second Edition

Overview

This textbook introduces the foundational concepts and tools needed for modern web design. It covers core Internet and web principles, building web pages with HTML5, and controlling layout, color, and typography using Cascading Style Sheets. Students learn how to work with images, multimedia, and design best practices, including accessibility, usability, and search engine optimization. The book also explains practical steps such as obtaining a domain name, choosing a web host, and publishing websites to the Web, making it ideal for beginners developing essential web design skills.
